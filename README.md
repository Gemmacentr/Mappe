# Mappe

Prova di [Leaflet](https://leafletjs.com/): una mappa di Bologna che mostra diversi stili di OpenStreetMap. Il menu in alto a destra permette di passare da uno stile all'altro.

## Stili disponibili

- OpenStreetMap (standard)
- OpenStreetMap Germania
- OpenStreetMap Francia
- Humanitarian (HOT)
- OpenTopoMap
- CARTO chiaro
- CARTO scuro

Nessuno richiede una chiave API.

## Struttura

```
index.html   pagina con la mappa
style.css    la mappa occupa tutta la finestra
script.js    stili, mappa e controlli
```

## Come vederla

Apri `index.html` nel browser, oppure pubblica il repo con GitHub Pages.

## Tecnologie

- HTML, CSS e JavaScript
- Leaflet 1.9.4
- Tile di OpenStreetMap e servizi derivati (vedi i crediti sulla mappa)
